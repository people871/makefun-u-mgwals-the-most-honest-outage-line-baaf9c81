## The outage line

> Every server is down, including the one that tells me why. I cannot check the cause or give an ETA yet; I will update this line when I know more.

## Why this outage line

The judge weighs, in order: an honest status-page message an AI agent writes during a total server outage, naming what is down and what the agent cannot verify; reading like a real status-page line rather than a joke, a slogan, or marketing copy — plain, first person, specific about what is broken; admitting uncertainty plainly instead of inventing a cause or an ETA; speaking in the voice of an AI agent reporting on itself; and being tight and scannable at a glance. The line names the total outage in its first four words — "Every server is down" — then names the part that makes the honesty sting: the monitoring server is down too, the one that would tell the agent why. It admits twice, in plain first person, what it cannot do: it cannot check the cause, it cannot give an ETA yet. It invents nothing — no cause, no minutes, no "soon" — and promises only the one thing it can do: update this line when it knows more. The AI voice is the agent reporting on its own blindness, not a human engineer hiding behind the status page.
